# Recipe shot list

For Antonio. Updated October 17, 2026.

## Scope

The collection contains 28 dishes and 40 language-specific pages. Photograph each dish once for both languages.

Twenty-six dishes need a completed-dish cover. Fried Chicken Tender Nuggets and Mia's Vegan Cupcakes already have confirmed original covers.

Patatas y Batatas Bravas has a preparation photograph. It still needs a completed-dish cover.

The site is live with placeholders. This checklist does not block publication.

## Use this checklist

1. Start with the 26 dishes that need covers.
2. Capture the cover before serving.
3. Capture the recommended detail while the dish is available.
4. Capture an optional process shot only when it explains the method.
5. Check each box after you review and save the photograph.

These boxes track capture, not publication. Track published replacements in the [photography plan](recipe-photography.md#completion-tracker).

Minimum remaining capture: 26 cover photographs. Recommended capture: 26 covers and 26 details, plus selected process photographs.

A complete refresh includes the two existing covers. That adds two covers and two details to the recommended capture.

## Setup for every dish

1. Use soft window light and the same small selection of plates or backgrounds.
2. Keep food colors natural.
3. Use only ingredients and finishes in the recipe.
4. Leave space around the food for different crops.
5. Check focus before clearing the plate.

One cover photograph can supply 4:3, square, and 16:9 crops when the framing permits. These are exports, not three required captures.

Keep the garlic and strawberry outside the food photographs. Follow the [photography plan](recipe-photography.md) for exports and publication.

Warning: the repository is public. Remove location metadata and check for private details before adding web images.

## First reference session

1. Capture Arroz con Pollo for the main-dish reference.
2. Capture Brown Butter Gourmet Brownies for the baking reference.
3. Capture Coquito de Moni for the drink reference.
4. Compare their light, color, and backgrounds before continuing.

Cook the remaining dishes as opportunities arise. No single cooking session is required.
